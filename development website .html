THE DIFFERENCE

Website as decoration vs. website as infrastructure.

Website as decoration

  • Template-led
  • Generic hierarchy
  • Desktop-first
  • Feature dumping
  • Random animation
  • Technology first

Website as infrastructure

  • Strategy-led
  • Purposeful hierarchy
  • Mobile considered from day one
  • Clear user journeys
  • Intentional interaction
  • Business problem first
